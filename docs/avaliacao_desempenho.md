# Enquadramento 

Este documento tem como finalidade definir, de forma clara e operacional, os requisitos e regras do sistema de Avaliação de Desempenho. Descreve os tipos de objetivos, as etapas do processo (autoavaliação, avaliação, entrevista e parecer), as funcionalidades necessárias e os formulários que suportam todo o ciclo avaliativo. O objetivo é garantir um modelo simples, padronizado e alinhado com as práticas da instituição.
