5. T7.8 — Gap conhecido (adiado)

ADIADO GET /validacoes/{gestaoLaboralUuid}/detalhes devolve [] (HTTP 200) para uma alteração de escalão.

Causa: "Alterar Escalão/Cargo" regista-se como UPDATE mas consolida criando um tiprel novo (clone). O clone só tem 1 snapshot inicial → todas as mudanças são InitialValueChange → o filtro de EDIÇÃO exclui-as → grelha vazia. Verificado live com a validação 01a03fb7-…d9ef.

Fix (a decidir depois): (a) tratar GESTAO_LABORAL como "criação" (mostra valores novos, sem o "antes"); ou (b) diff cross-instância tiprel-novo↔tiprel-anterior (antes→depois reais). Documentado em JaversValidacaoDetalheReadService (TODO T7.8) e no handoff §5b.

Comportamento atual ([], não é erro) é inofensivo para o frontend e não bloqueia o merge.
