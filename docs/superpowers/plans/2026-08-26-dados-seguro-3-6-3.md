> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:
> executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete specification section 3.6.3 by supporting the institution mobile number and active insurance policies
by island.

**Architecture:** Extend the existing versioned institution resource with `telemovel`. Model `RH_T_DADOS_APOLICE` as a
separate versioned resource: one active policy per island, with updates inactivating the current row and inserting a new
active row; command/query handlers expose save and active-list operations through the SOAT controller.

**Tech Stack:** Java 23, Spring Boot 3.5, Spring Data JPA, iGRP CommandBus/QueryBus, Jakarta Validation, OpenAPI, JUnit
5, Mockito.

```java
@Transactional
public synchronized DadosApoliceResponseDTO salvarDadosApolice(
    DadosApoliceRequestDTO request) {
  dadosApoliceRepository
      .findFirstByIlhaIdAndEstadoOrderByIdDesc(request.getIlhaId(), Estado.A.getCode())
      .ifPresent(current -> {
        current.setEstado(Estado.I.getCode());
        dadosApoliceRepository.saveAndFlush(current);
      });

  var policy = new DadosApoliceEntity();
  policy.setUuid(UuidCreator.getTimeOrderedEpoch().toString());
  policy.setEstado(Estado.A.getCode());
  policy.setNumApolice(request.getNumApolice());
  policy.setIlhaId(request.getIlhaId());
  policy.setDataApolice(request.getDataApolice());
  return toResponse(dadosApoliceRepository.save(policy));
}
```

- [x] **Step 3: Add active policy list**

@Transactional(readOnly = true)
public List<DadosApoliceResponseDTO> listarDadosApoliceAtivos() {

}
